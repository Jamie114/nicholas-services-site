# Residential duty model — reviewed 2 November 2026

The model estimates ordinary residential home purchases, assuming full acquisition, dutiable value equals entered price, and all buyers qualify for any applied concession. First-home duty relief is now applied automatically where available when First home buyer is selected; the user can switch it off for ineligible buyers. Existing first-home cases recalculate using this new default. It uses rules reviewed on 2 November 2026; it does not determine eligibility. Contract/settlement dates, ownership shares, residency, foreign surcharges and special relief require independent checking. Vacant land, separate construction, off-the-plan valuation discounts, historical contracts, mixed eligibility, and other special relief are not modelled. The NT package exemption has a separate assumed-eligibility option. TAS historical relief is not modelled. Rates change and must be reviewed before reliance.

The 5% Deposit Scheme check uses the selected state and area price cap and assumes other eligibility, location and valuation are verified with a participating lender. Area cannot be inferred from state alone. The professional/lender LMI waiver is an explicit assumption. LMI without a waiver is only an indicative approximation.

For the two-property scenario, only purchase duty uses the chosen state; the existing land-tax and running-cost estimates retain Victorian assumptions. Verify land tax separately, especially because it uses land value, not purchase price.
